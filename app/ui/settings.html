My themes

Every theme you have. ★ up to ten favourites: they come first in the picker, the quick switcher and the menu (also palette fav).

Themed apps

Everything is on by default. Switch an app off to keep its own look: Palette takes its line out of that app's config (backed up first) and restores it.

Get themes

Community themes made for Omarchy; they work here too, wallpapers included. The list is built in, so browsing stays offline; Install downloads that one theme. Palette takes only its colours, wallpapers and preview, never config files or scripts.

Wallpapers

Each theme has its own wallpapers. Switching to a theme shows the starred one (click ☆ on a wallpaper, here or in the picker), or its first; a theme with none leaves your desktop alone.

Library

Pictures kept for any theme, in one folder. Add one to a theme only if you want to. Palette never deletes them on its own: remove what you don't need here, or tidy the folder in Finder.

Colours

Change any colour of a theme. Your changes sit on top of the theme's own colours, so Reset always brings the original back. If it's the active theme, every app updates as you go.

Get the tools

The programs Palette themes but doesn't ship. Palette never installs anything itself: copy a command, paste it into Terminal, and it runs there, where you can see it.

Setup

Set up all apps
Adds Palette's line to each switched-on app's config (backed up first), then reloads them
Re-apply the theme
Renders the current theme again (after editing starship.toml, say)
Remove Palette from all configs
Every app back exactly as before Palette; your themes and wallpapers stay. Obsidian keeps Palette's colours until you reopen it (or switch off Settings → Appearance → CSS snippets → palette)

Move to another Mac

Export makes a plain folder with your themes and settings (and, if you like, wallpapers and app configs). Copy it over with AirDrop, a USB stick or a private git repo, then Import it on the other Mac.

Bar

        
Your SketchyBar, built from pills. Drag items to reorder them or move them between pills, Pill ◀ ▶ moves a whole pill,
          click one to change it, and press Apply. Colours follow the theme.

        

      

      

        
Windows

        
AeroSpace's gaps, layout, workspaces, app rules and keyboard shortcuts. Palette changes
          these key by key in your aerospace.toml; comments and everything else stay as you wrote them.

        

      

      

        
Borders

        
The coloured outline JankyBorders draws around windows. Changes show straight away.

        

      

      

        
Prompt

        
Your Starship prompt, built from coloured blocks. Palette changes your starship.toml key by
          key; other settings and comments stay. Colours follow the theme.

        

      

      

        
Dock & menu bar

        
macOS's own settings, the same switches as in System Settings. They change straight away,
          and switching back is the same switch.
